# CS360

 1. Requirements and Goals

The main goal of my app was to create an event-tracking application that would make it easier for users to organize and manage their events in one place. The app needed to allow users to add, edit, view, and delete events while keeping the information organized. I wanted the app to address the need for a simple way to keep track of important events without making the process complicated or overwhelming.

 2. Screens, Features, and User-Centered Design

The main screens and features included the event list, adding and editing events, viewing event information, and deleting events. I focused on keeping the layout simple and making the buttons and fields easy to understand. I also tried to make the navigation feel natural so that users would not have to spend a lot of time figuring out how to use the app. These designs were successful because the user could complete the main tasks without unnecessary steps.

 3. Approach to Coding

When coding the app, I worked on the application one feature at a time instead of trying to build everything at once. I focused on getting the basic functionality working first and then added additional features. I also used comments and organized my code so I could understand what each section was doing. This approach helped me troubleshoot problems when something did not work correctly. I could use the same strategy in future projects by breaking larger projects into smaller, more manageable tasks.

 4. Testing

I tested the app by running it and checking each of the major functions. I tested adding new events, editing existing events, viewing information, and deleting events. I also paid attention to errors that occurred while developing and made changes when necessary. Testing is important because code can look correct but still have problems when it is actually used. Testing helped me find issues and make sure the different parts of the application worked together as expected.

 5. Innovation and Overcoming Challenges

One of the biggest challenges for me was learning how all of the different parts of Android Studio worked together. Since I was still learning mobile app development, I had to troubleshoot issues with the project structure, layouts, Java code, and database functionality. I overcame these challenges by working through the problems step by step instead of trying to fix everything at once. This helped me better understand how the user interface, code, and database connect to create a complete application.

 6. Area Where I Was Most Successful

I think I was most successful in demonstrating my skills with the event management functionality and database integration. Getting the app to store and manage event information showed me how the different parts of the application work together. I was also proud of being able to create an interface that was simple enough for a user to understand while still providing the features needed by the app. This project gave me more confidence in my ability to develop a mobile application from planning through implementation and testing.
